# CommunityCAD

> [!WARNING]
> **Experimental community-maintained modernisation — not production-ready.**
> This repository is an independent development effort to modernise CommunityCAD. Features, APIs, database schemas, deployment procedures and behaviour may change without notice. Some functionality may be incomplete, unstable or untested. **Do not deploy to a live/production CAD or rely on it for real emergency services.** Back up your data before testing upgrades. This project is not the official CommunityCAD release.
